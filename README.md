# CEN100 Guide: Don't Lose Marks

A student-created course companion for **CEN100: Introduction to Engineering**, Fall 2026, at Toronto Metropolitan University. Prepared for **Section 29, Group 9**, the guide brings project milestones, individual tasks, and submission checklists into one mobile-friendly page.

## Features

- Upcoming deadlines with countdowns.
- Separate views for team deliverables, individual work, and course rules.
- Expandable milestone checklists with requirements and common mark-loss pitfalls.
- Checklist progress saved locally in the browser.
- Automatic light and dark appearance based on the device setting.
- A dedicated section for confirmed instructions and items that still need clarification.

## Using the guide

1. Open the published guide in your browser.
2. Select **Team**, **Individual**, or **Rules**.
3. Tap a milestone to review its requirements and tick completed items.
4. Use **Clear my ticks** to reset progress on the current browser.

Progress is stored in browser local storage. It is personal to that browser and does not sync between devices or team members. Clearing browser data may remove saved progress.

## Course information

This is an unofficial planning aid based on Fall 2026 CEN100 materials and recorded course clarifications. Check D2L and current instructor, GA, or project manager instructions for authoritative requirements and deadlines. The guide identifies unresolved items in its **Still open** section.
